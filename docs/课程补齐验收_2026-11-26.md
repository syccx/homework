## 本轮完成内容

在原有个人待办功能外增加独立网络示例页面。首页进入 `NetworkPage` 后直接加载，不依赖 `EntryAbility` 或 Preferences 初始化；使用 Navigation 入栈和返回。远端正常、空列表、HTTP 错误三个场景分别访问 JSONPlaceholder 的固定路径。正常场景每次从真实响应取五项，第 1 组为第 1–5 条，第 2 组为第 6–10 条，切换组会重新请求，普通刷新保持当前组。请求禁用缓存；失败保留上次成功数据及来源组标记，空成功结果清空远端视图。

使用原生 `DataPanel` 圆环展示接口数据中已完成、未完成的数量和比例，列表与图表使用同一份 V2 状态。个人待办列表及原有本地七天趋势不因网络页刷新而被覆盖。

修复首页筛选数字停留在初始值的问题：`filterChip` 不再接收构建时计算出的普通数字快照，改在数字 `Text` 的更新表达式中直接读取仓库计数，使新增、完成、移入回收站和恢复后的变化保持响应式依赖。本地检查覆盖已挂载筛选项而非只读取仓库最终值。网络 Store 也在修改场景和样本组前校验参数，避免非法值破坏后续刷新。

加入可选预览网络设置。默认使用系统代理，可在当前预览会话输入 HTTP 代理主机和端口，应用后请求当前场景；支持恢复系统设置。配置不落盘，不包含密码，不在源码中绑定本机代理地址。请求进行中禁止修改代理。输入校验覆盖主机格式、换行、空项和端口范围。
