# TodoApp 课程要求补齐计划

日期：2026 年 11 月 26 日。范围：在现有工程上补齐可操作的远端数据展示、真实版本管理和课程文档。保留个人待办及现有布局风格。

## 设计

新增独立的“网络示例”业务页，由首页入口通过 Navigation 打开。页面出现时直接调用网络状态仓库加载远端数据，不依赖 EntryAbility、Preferences 或设备签名。正常、空数据和 HTTP 错误演示均访问远端公开测试接口，不以本地固定数组冒充请求。刷新可重复请求；失败保留上次成功数据并显示错误；网络示例不写入个人待办。

图表使用原生 DataPanel 展示远端返回列表的已完成和未完成占比，随每次成功请求更新；这与原有本地七天趋势分别标注。页面采用现有 Theme 和状态管理 V2。

## 执行步骤

- [x] 备份现有源码和外部报告，建立真实 Git 基线，明确此前开发历史缺失。
- [ ] 为网络状态仓库添加首次加载、重复刷新、空数据、失败、并发及个人数据隔离测试，先观察失败。
- [ ] 实现远端场景接口、网络状态仓库、网络业务页、DataPanel 图表和首页导航入口。
- [ ] 执行全部回归检查及 HarmonyOS 构建，检查实际预览能力和可用证据，准确记录验证边界。
- [ ] 修订报告、README、项目说明和本轮验收记录，关联已有运行截图，移除不实陈述。
- [ ] 分阶段提交真实改动，保存 git log 文本并获取实际记录截图，核查忽略规则和敏感配置。
- [ ] 同步可交付源码与文档到 OneDrive 备份，提供仍需本人处理的事项。

## 验收及边界

自动检查通过不能替代 Previewer 内实际 HTTP 和交互验证。报告对截图来源、历史记录起点和待验项分别说明。本人姓名、学号、班级、选题登记、老师附件模板、公开仓库账号及地址不得编造。尚无模板时修订 Markdown 内容稿，不宣称已满足模板版式。所有提交以实际时间生成，维护提交使用 Codex 工具身份，不冒用学生身份，不补造过去的开发历史。
