# 示例任务页面体验改进实施计划

**目标：** 让网络示例默认成为清楚、紧凑的只读任务浏览页，同时保留课程联网与异常演示能力。

**范围：** 只改 NetworkPage、首页对应入口和网络回归检查；不改个人仓库、API地址、数据来源或应用其他模块。沿用现有深色主题与翠绿色强调色。既有报告截图保留原采集时点，新UI不冒充已经重新截图。

## 页面与行为

- 首页入口、页面标题使用“示例任务”，说明“公开任务，仅供查看”。
- 主视图保留返回、正常刷新、小圆环与完成数量、任务列表和“换一组”。不显示GET路径、代理地址或场景选择按钮。
- “演示设置”默认收起；展开后可进入正常、空列表、404测试，查看接口说明并设置会话代理。
- 页面重新进入与普通刷新显式加载normal。若既有请求仍在途，等待其结束，再恢复normal；不修改NetworkStore的并发和数据隔离逻辑。
- 空态和失败给出“重新加载示例”的可达操作；错误时保留旧数据并明确“上次加载结果”。原场景重试留在展开设置中，避免普通用户反复请求404。
