1. 在 DevEco Studio 打开正式工程，完成 Sync；外部修改后重新加载磁盘文件。打开 `entry/src/main/ets/pages/Index.ets` 并刷新 Previewer。

3. 点击待办文本区编辑，只改标题或描述并保存，再次打开确认读取的是新内容。切换完成/取消完成，观察计数、筛选和进度；左滑删除后进入回收站并恢复，按需截图或录屏。
4. 点击首页“示例任务”，观察进入独立只读页面；“演示设置”默认收起，首屏展示简短说明、96vp圆环与横向统计及任务列表。该页自行发起正常请求，无需 EntryAbility 或本地存储初始化。默认使用系统代理；若实际无法联网，先展开“演示设置”，再展开“预览网络设置”，填写本人已知可用的 HTTP 代理主机和 1–65535 端口，再点“应用并请求”。主机不填 `http://`、路径或端口；设置只在本次会话保留，可“恢复系统代理”。完成配置后收起设置再拍普通浏览画面。
