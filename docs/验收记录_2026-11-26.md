| 范围 | 原问题 | 本轮处理 |

| 表单 | 两个优先级控件各占 100% 宽度，无滚动，日期时分不可控 | 分段等分、内容可滚动；新设日期默认 18:00，新增时分选择与未保存返回确认 |
| 统计 | 主进度分母含回收站；同一截止时间未继续比较优先级 | 统一有效任务计数，补齐排序后续比较；统计排除未来完成时间 |
| JSON 备份 | 只有导出，没有恢复入口 | 增加整批校验、合并导入、冲突编号修复；无效批次不部分写入 |
| 卡片刷新 | 内存 ID 注册表在重启后丢失，刷新读取未初始化 Store | 使用系统已发布实例查询；系统刷新读最新已保存快照，主动更新串行合并 |
| 模块配置 | 缺网络权限，卡片定时更新关闭，名称仍为模板文字 | 添加 INTERNET 权限、启用间隔刷新、修正中英文名称资源 |
